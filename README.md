## Задание 5. Алгоритмы поиска
### Алгоритм решения
1. Ввести количество элементов списка "N" с проверкой ("N > 0").
2. Считать элементы во временный вектор и создать список "L" с помощью конструктора от итераторов.
3. Вывести исходный список с помощью итераторов.
4. Определить лямбда-выражение "isNegative", возвращающее "true", если элемент меньше нуля.
5. Первый вызов "find_if" — найти первый отрицательный элемент "first_neg".
6. Если "first_neg == L.end()" (отрицательных элементов нет), список оставить без изменений.
7. Иначе сформировать итератор "after_first", следующий за первым отрицательным элементом.
8. Второй вызов "find_if" — найти второй отрицательный элемент "second_neg", начиная с "after_first".
9. Если второй отрицательный элемент не найден, границей удаления служит "L.end()" (удаляется всё после первого отрицательного). Если найден — границей служит "second_neg" (удаляется только диапазон между отрицательными элементами).
10. Выполнить **один вызов** "L.erase(after_first, finish)". Сами отрицательные элементы не удаляются, так как начало диапазона находится после первого отрицательного, а конец — на втором отрицательном (не включается).
11. Вывести результат с помощью итераторов.
