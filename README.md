## Задание 1. Заполнение и доступ к элементам. Обратные итераторы
### Алгоритм решения
1. Ввести количество элементов "N" с проверкой: "N > 0" и "N" делится на 3.
2. Считать "N" целых чисел во временный вектор "temp".
3. Создать список "L" с помощью конструктора от итераторов: "list<int> L(temp.begin(), temp.end())".
4. Вывести исходный список, используя прямой итератор в цикле "for".
5. Вычислить размер одной трети: "third = N / 3".
6. **Первая треть в прямом порядке:** пройти циклом по списку от "L.begin()" до тех пор, пока не выведено "third" элементов. Использовать обычный итератор.
7. **Вторая треть в обратном порядке:** пройти циклом по списку, используя обратные итераторы "L.rbegin()" / "L.rend()". Пропустить первые "third" элементов (это последняя треть исходного списка), затем вывести следующие "third" элементов.
8. **Третья треть в обратном порядке:** пройти циклом по списку, используя обратные итераторы "L.rbegin()" / "L.rend()", вывести первые "third" элементов.
