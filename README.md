содержит отрицательных элементов, то не изменять его, если отрицательный элемент всего

### Текст задачи
Дано число N (> 0) и дек D. Добавить в начало дека последовательность чисел 1, 2, …, N, а в его

одинаковым параметром — функциональным объектом, а также итераторы вставки,
возвращаемые функциями front_inserter и back_inserter.

4. Создать один функциональный объект — лямбда-выражение "generator", которое захватывает счётчик "counter" по ссылке, возвращает его текущее значение и уменьшает на 1. При "counter = N" объект последовательно выдаёт "N, N−1, …, 1".

## Задание 7.1. Сортировка и слияние
### Текст задачи
Дан вектор V с нечетным количеством элементов N (≥ 3). Определить значения трех средних
элементов вектора после того, как вектор будет отсортирован (по возрастанию), и вывести их в
порядке возрастания. Использовать алгоритмы nth_element (для нахождения центрального
элемента), max_element (для нахождения элемента, предшествующего центральному) и
min_element (для нахождения элемента, следующего за центральным).
### Алгоритм решения
1. Ввести количество элементов "N" с проверкой: "N" нечётное и "N ≥ 3".
2. Считать элементы и создать вектор "V" конструктором от итераторов.
3. Вывести исходный вектор.
4. Определить итератор центральной позиции: "center = V.begin() + N / 2".
5. Вызвать "nth_element(V.begin(), center, V.end())". Алгоритм частично упорядочивает вектор так, что в позиции "center" стоит медиана, все элементы слева от неё не превосходят её, а все элементы справа — не меньше её.

7. Значение "*center" — средний (медианный) элемент.
8. Вызвать "min_element(center + 1, V.end())" — минимум правой части равен элементу, который в отсортированном векторе стоит **после** центрального.
9. Вывести три найденных значения. Порядок вывода автоматически является возрастающим, поскольку: "максимум левой части ≤ медиана ≤ минимум правой части".

5. Алгоритм "includes" возвращает "true", если каждый элемент первого мультимножества присутствует во втором **с учётом кратности**. Например, если в "V0" число 2 встречается дважды, то и в "Vi" оно должно встречаться не менее двух раз.
6. Если результат "true", увеличить счётчик подходящих векторов.
7. После цикла вывести найденное количество.
